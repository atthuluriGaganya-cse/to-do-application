# To-Do List

A simple and responsive frontend-only To-Do List application built with React. It allows users to create, organize, search, filter, edit, and manage their daily tasks efficiently.

## Features

- Add new tasks
- Assign priorities:
  - High
  - Medium
  - Low
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Search tasks by title
- Filter tasks by:
  - All
  - Active
  - Completed
- Filter tasks by priority
- View task statistics:
  - Total Tasks
  - Completed Tasks
  - Pending Tasks
- Persist tasks using Browser Local Storage
- Responsive design for desktop and mobile devices

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
- Lucide React
- Local Storage

## Project Type

This is a **frontend-only application**.

It does not use:

- Backend
- External database
- Server-side application logic

Task data is stored locally in the browser using `localStorage`.
